# GREEN API Example

Прототип Telegram-чата на React и TypeScript.

## Архитектура

- **Чат независим от GREEN API:** он работает через интерфейс `ChatClient`. Адаптер находится в `src/integrations/green-api`; для другого API достаточно реализовать этот интерфейс и подключить новый адаптер в слое сессии.
- Проект организован по FSD.
- Zustand управляет состоянием, TanStack Query — запросами и мутациями.
- Zod валидирует ответы API и состояние, восстанавливаемое из localStorage.
- Ant Design используется для UI-компонентов.

## Ограничения прототипа

- Данные доступа пользователя, включая API-токен, хранятся в localStorage.
- Виртуализация списка и подгрузка истории при прокрутке не реализованы.
- Используется i18next, доступен только английский язык. Готовые строки в состоянии и константах не обновляются реактивно при смене языка.

## Дисклеймер об использовании AI

- При разработке использовались AI-агенты. Я проверял результат и дорабатывал его за много итераций; ответственность за кодовую базу полностью лежит на мне.
- Глубина проверки соответствует задачам прототипа. Для использования в продакшене потребовалась бы более тщательная проверка.

## Запуск в режиме разработки

```bash
npm ci
npm run dev
```

Откройте адрес из терминала и введите данные инстанса GREEN API: API URL, ID и токен.

## CI и GitHub Pages

При пуше в `main` GitHub Actions проверяет и собирает приложение, затем автоматически разворачивает его на GitHub Pages. Адрес: https://dkskv.github.io/green-api-example/.
