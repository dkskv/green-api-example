# Инструкции для агентов

- Пиши названия тест-кейсов (`it`, `test`, включая параметризованные тесты) и групп (`describe`) на русском языке. Технические идентификаторы и значения протокола можно сохранять в исходном виде.
- Пиши комментарии в коде на русском языке. Не переводи служебные директивы инструментов, например `@vitest-environment`, `@ts-expect-error` и `eslint-disable`.
- Размещай тесты рядом с проверяемым модулем: `<имяМодуля>.test.ts`, а при наличии JSX — `<имяМодуля>.test.tsx`. Сценарии взаимодействия нескольких модулей выделяй в `<название>.integration.test.ts` или `.tsx`.
- Каждый тест должен проверять связный сценарий. Не объединяй независимые сценарии и не дублируй проверки без отдельного поведенческого риска.
- После изменения тестов запускай `npm test`, `npm run lint` и `npm run build`.
